## How to read it

- Each entry lists code per macOS tier. At run time the newest tier whose version is at or below the running macOS wins; every entry has a macOS 12 path.
- **Rule:** use what Apple's own apps use for that role on that macOS version. Standard controls become Liquid Glass on 26+ by themselves ("automatic"); explicit glass APIs are used only where Apple uses them (toolbars, floating controls).
- **Runs as:** SwiftUI (hosted in an NSHostingView), AppKit (where SwiftUI has no equivalent, or is built on that AppKit view), *already native* (winemac does it today), *stays wine* (the app draws it itself).
- **Improvised:** composed from other elements because macOS has no direct counterpart.

### Group box
<a id="buttongroupbox"></a>`button.groupbox` · SwiftUI · Liquid Glass: —

- Windows: `Button` BS_GROUPBOX
- Replaces visual parts: BUTTON/BP_GROUPBOX, BUTTON/BP_GROUPBOX_HCDISABLED
- Windows → view: WM_SETTEXT, WM_WINDOWPOSCHANGED

**AppKit, macOS 12+**

```swift
let box = NSBox()
box.boxType = .primary
box.title = "Options"
box.titlePosition = .aboveTop
```

**SwiftUI, macOS 12+**

```swift
GroupBox(label: Text(title)) { Color.clear.frame(maxWidth: .infinity, maxHeight: .infinity) }
```

A real NSBox (SwiftUI's GroupBox on macOS). Win32 group boxes don't contain their controls: they're siblings drawn on top, placed by the app a caption's height below the box's top. macOS puts a box's title above the box (HIG Boxes), so when nothing of the app's sits in that band the title goes there: the host view reaches above the Win32 rectangle by the title's height (winemac w2sSetOutsetTop:) and the box takes the rectangle, whose caption band becomes its top padding. Without room, the title goes inside the box's top (belowTop), still the real NSBox. The box stays behind the native controls it contains, and its fill is translucent, so what wine draws inside shows through. Room is looked at again once the dialog is built and when the box moves.

```swift

  Button(note, action: action)
} label: {
  Text(title)
```

The arrow half raises BCN_DROPDOWN; the app then calls TrackPopupMenu, and that menu is translated by menu.popup and shown from the arrow. BCSS_NOSPLIT makes both segments open the menu.
